# Riot Client path fallback

Implemented on `employee-riot-launch-poc`. No frontend/backend changes, commit or push for this task.

1. **Paths:** `ClientConfig.cs` owns validation, discovery and JSON persistence; `Program.cs` owns the native picker and branded fallback UI. `RiotLauncher.cs` integrates discovery. `build.ps1` references the built-in JSON serializer. `Tests.cs` adds isolated config tests. `PickerReview.cs` / `review-picker.ps1` are optional visual review tooling, excluded from the production build.
2. **Config:** `%LOCALAPPDATA%\ASCEND\launcher-config.json`, JSON key `riotClientPath`. No upload, frontend storage or backend request. Writes use a same-directory temporary file and atomic replacement; redirected output paths are refused. Failed validation leaves the previous config intact.
3. **Discovery:** validate saved JSON first, then common OS-drive / Program Files / C / D / E Riot Games paths, then the existing owned registry ClientPath. Invalid saved paths are ignored. Only total failure shows the selection UI. The old registry remains a compatibility source; the picker saves JSON.
4. **Picker:** WinForms `OpenFileDialog`, single selection, file/path must exist. Cancelling keeps the fallback screen. Missing UI includes “Không tìm thấy Riot Client”, the ASCEND explanation, “Chọn Riot Client”, “Đóng” and the required filename note. Error UI includes “Thử lại” and “Chọn lại đường dẫn Riot Client”.
5. **Filename:** only absolute readable regular files named `RiotClientServices.exe` (case insensitive) pass. Other executable names, scripts and `.lnk` are rejected before execution.
6. **Signature:** existing Authenticode WinVerifyTrust and Riot Games publisher checks remain required, including re-verification before spawning. No arbitrary arguments are accepted from the picker or URI.
7. **Wrong file:** automated rejection tests pass for Notepad, PowerShell, cmd, bat, ps1, com, scr and shortcuts. Required error: “File đã chọn không phải RiotClientServices.exe.” Real unsigned and Microsoft-signed non-Riot rejection tests also pass.
8. **Custom location:** isolated custom-directory validation/persistence tests pass. Valid picker selection saves the path, displays “Đã tìm thấy Riot Client” briefly and resumes the launch automatically. Actual mouse-driven picker completion has not been confirmed: the review window disappeared during Computer Use observation; recovery found no remaining window. No Riot installation files were moved to force a missing-client case.
9. **Saved reuse:** fresh config-instance test confirms saved path takes priority over common paths. Atomic replacement of an existing config passes.
10. **Invalid saved path:** deleted file, malformed JSON and JSON `null` recover to common detection. These use isolated temporary fixtures; signature rejection is tested separately.
11. **No console:** production EXE retains Windows GUI subsystem 2, native CreateProcess launch and no PowerShell/CMD runtime dependency. Build assertion and icon/resource tests pass. The build/installer scripts use PowerShell only during development/installation.
12. **Visible Riot:** final installed EXE auto-detected `E:\Riot Games\Riot Client\RiotClientServices.exe`, launched fixed League service args plus modern UI, and logged `VISIBLE_WINDOW_FOUND` at `2026-10-07T13:42:51.903Z`. Common-path selection itself is tested with fixtures; a physical C-drive installation was not available.
13. **Auto-close:** the final real launch logged SUCCESS then LAUNCHER_CLOSED at `13:42:52.676Z`, approximately 0.8 seconds later. Existing-window focus/no-duplicate behavior remains covered by engine tests. Icon and body branding tests pass. Installed and built SHA256 match: `0E228E8F34F26B8F781360CCF8B9CDA2462E8F8700C30122E3AEE431A5792430`.

Validation command: `tools/ascend-launcher/build.ps1 -Test`. Config atomic-replacement tests required running outside the managed sandbox, which denied `File.Replace` on a temporary test file; the elevated test run passed.

For manual picker review, run `review-picker.ps1`, then launch `dist/PickerReview.exe`. It deliberately omits automatic candidates and uses `dist/picker-review-config.json`, leaving live JSON and registry configuration alone. Selecting a real signed Riot service executable continues the real native launch flow. Production has no test-mode URI or command-line switch. The installed protocol still points directly to `%LOCALAPPDATA%\ASCEND\RiotLauncherPoC\AscendLauncher.exe`.
