# Launcher Home, protocol management and delayed Riot opening

1. **Protocol states:** `ProtocolRegistration.cs` reads `NOT_INSTALLED`, `INSTALLED` or `BROKEN`. Installed requires URL Protocol marker, existing current EXE and exact quoted current-path command. Foreign ownership/machine-level conflicts are reported. No-argument startup displays Home and never starts a countdown or silently registers.
2. **Install:** the explicit CÀI/SỬA button registers the runtime `AscendLauncher.exe`, then rereads and verifies Registry before showing success. A fresh setup copies files and registers the app uninstall entry; the user opens launcher and installs the protocol separately. Existing registration is retained during updates.
3. **Remove all ASCEND protocols:** confirmation explains browser integration will stop. Only known `ascendriot`, `ascend`, `ascendgame` handlers with ASCEND ownership or the exact current command are removed. Foreign entries are retained and reported. Cancel/removal stops the countdown. After removal Home stays open with CÀI GIAO THỨC. Executables, local config, Riot and Employee data are untouched.
4. **Keys:** HKCU `Software\Classes\ascendriot` with `(Default)`, empty `URL Protocol`, Owner, DefaultIcon and `shell\open\command`. Removal only visits the known ASCEND scheme names under HKCU Classes; no HKLM writes or Windows/third-party protocol enumeration/deletion.
5. **Ownership:** recognized markers `ASCEND.Launcher.v1` and legacy `ASCEND.RiotLauncherPoC.v1`, or exact current EXE command with no conflicting owner. Tests preserve a foreign `ascendgame` and an unrelated `http` sentinel. Broken owned paths can be explicitly repaired.
6. **Countdown:** `AutoLaunchCountdown.RIOT_AUTO_LAUNCH_DELAY_SECONDS = 60`; monotonic Stopwatch clock, one WinForms flow timer, real remaining seconds and gold progress bar. An isolated test with the actual timer recorded 50/40/30/20/10/0 at 10/20/30/40/50/60 seconds, zero spawns before expiry and one afterwards. The first visible wall-clock test was closed early; the final private test ran the full delay successfully.
7. **Open Now:** stops the timer and invokes the existing launch engine immediately. A native form test verifies one launch without waiting for the fake clock to expire.
8. **Cancel/close:** HỦY returns Home. Closing cancels the lifetime wait and disposes/stops the timer. Tests verify no later spawn. Repeated forwarded URIs neither restart the countdown nor create a second timer; a Home instance receives a new allowed URI through bounded WM_COPYDATA.
9. **Already running:** verified existing UI is restored/focused before countdown; it is checked during countdown too. Tests verify zero spawns and immediate focus/close for both cases. Service-only process presence is still not success.
10. **Missing Riot:** saved/common/metadata discovery and native picker/signature checks remain. Missing initially or deleted during countdown keeps RIOT_NOT_FOUND UI open with choose/retry/remove. A validated selected path resumes preparation or launch depending on whether the delay has already elapsed.
11. **Auto-close:** UI tests verify success closes after the existing 750 ms delay, or 500 ms when already running. Self-test remains two seconds without Riot lookup/spawn. No Riot/game process was killed.
12. **PowerShell visible:** NO runtime PowerShell/CMD invocation. Launcher/setup remain x64 Windows GUI subsystem binaries, resource-embedded ASCEND icon. PowerShell is used only by developer build/install verification commands.
13. **Web flow:** plain user-click anchor remains `ascendriot://open/league`; no Next Link, delayed navigation or backend call. Production browser review passes mobile/desktop modal bounds, URI requests, helper text and download hash.
