# Country flag artwork

Source: https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3
Version: 7.3.2. License: MIT; included in LICENSE.

249 ISO 3166-1 country/territory SVG files, imported unchanged from the 4:3 collection. Shared by language navigation, account dashboard, phone country selection and coach profiles. Flags represent the country mapped in the UI, rather than all regions that speak a language.
